## Image Guidelines

- **Format**: Use SVG for logos and icons, WebP/JPEG for photos
- **Optimization**: All images should be optimized for web
- **Responsive**: Provide multiple sizes where needed
- **Alt Text**: Always include descriptive alt text in HTML
- **Lazy Loading**: Use data-src attribute for lazy loading

## Logo Usage

- Primary logo: `idigital-logo.svg` (dark backgrounds)
- White logo: `idigital-logo-white.svg` (dark backgrounds)
- Favicon: `favicon.ico` (32x32, 16x16)
